# Dompetku — Finance Manager 💰

Dompetku adalah aplikasi web pengelolaan keuangan pribadi yang dirancang untuk membantu pengguna mencatat, memantau, dan mengelola pemasukan serta pengeluaran secara praktis dan terorganisir dan data nya tersimpan pada chache chrome masing masing jadi tidak memiliki database jadi semua orang dapat menggunakan nya tanpa harus khawatir data nya terlihat oleh orang lain jadi datanya akan hanya tersimpan pada device masing masing.

Aplikasi ini menyediakan dashboard interaktif yang menampilkan ringkasan saldo, total pemasukan, pengeluaran, serta sisa uang pada bulan berjalan. Pengguna juga dapat mengelola riwayat transaksi dan melihat laporan keuangan bulanan melalui visualisasi grafik.

## ✨ Fitur Utama

- **Dashboard:** Menampilkan ringkasan saldo dan kondisi keuangan.
- **Pencatatan Transaksi:** Menambahkan transaksi pemasukan dan pengeluaran.
- **Riwayat Transaksi:** Melihat, mencari, dan memfilter transaksi.
- **Rekap Bulanan:** Menampilkan perbandingan pemasukan dan pengeluaran setiap bulan.
- **Grafik Keuangan:** Visualisasi arus keuangan selama enam bulan terakhir.
- **Edit dan Hapus Transaksi:** Mengelola data transaksi yang sudah dicatat.
- **Dark Mode:** Tampilan mode gelap untuk kenyamanan pengguna.
- **Responsive Design:** Tampilan yang menyesuaikan berbagai ukuran layar.

## 🛠️ Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript (ES Modules)
- Node.js (untuk kebutuhan pengujian)

## 🎯 Tujuan Proyek

Dompetku dikembangkan untuk mempermudah pengelolaan keuangan pribadi, membantu pengguna memahami arus keuangan, serta membangun kebiasaan mencatat pemasukan dan pengeluaran secara lebih teratur.
